# استاندارد لیست‌ها — تصمیم کاربر، ۲۰ اکتبر ۲۰۲۶

**تمام لیست‌های موجود و جدید از AG Grid استفاده می‌کنند.** مرجع، لیست محصولات پروژه محلی اورنزا است. تبدیل لیست‌های فعلی انجام شده و این قاعده صرفاً برنامه آینده نیست.

## آخرین اصلاح کاربر: فیلتر داخلی و تم خنثی

تمام فیلترهای لیست داخل AG Grid هستند؛ فرم جست‌وجو و select وضعیت بیرون هنرجویان حذف شده‌اند. ستون «هنرجو (نام، کد یا تماس)» جست‌وجوی جامع را در سرور انجام می‌دهد و ستون‌های کد، تماس و وضعیت نیز فیلتر مستقل دارند. Floating Filter در خود گرید فعال است؛ popup ستون برای عملگرها و شرط‌های پیشرفته باقی است. q/status لینک قدیمی به فیلتر قابل مشاهده گرید تبدیل و از URL جدید حذف می‌شوند، نه اینکه فیلتر مخفی باقی بمانند.

در تب حضور و غیاب، تمام جلسات در یک AG Grid با ستون قابل فیلتر «ترم» قرار دارند؛ select ترم بیرون حذف شده است. لینک مستقیم ترم/جلسه حفظ و فیلتر ترم در خود گرید فعال می‌شود. کارت‌های خلاصه در تب ترم‌ها و فرم‌های عملیات حفظ شده‌اند.

**رنگ مرجع اورنزا کنار گذاشته شده است.** زمینه گرید و ردیف‌ها سفید، سرستون طوسی روشن `#f3f4f6`، حاشیه `#e5e7eb` و متن/آیکون طوسی‌اند. حالت hover، فیلتر فعال و popup نیز خنثی هستند؛ badge وضعیت، معنای عملیاتی خود را حفظ می‌کند. مرجع اورنزا صرفاً برای رفتار/ساختار است، نه رنگ‌ها. مشخصات رنگ گرم در بخش زیر، سابقه مرجع قبلی‌اند و معیار فعلی نیستند.

## مرجع و پیاده‌سازی

- `../orenza/src/components/admin/AdminResourceList.astro`: عنوان، راهنمای فیلتر، شمارنده، اقدام افزودن و قاب جدول.
- `../orenza/src/scripts/admin.ts`: AG Grid Community با تم Material، RTL، متن فارسی، ردیف ۵۶ پیکسل و سرستون ۵۲ پیکسل، فیلتر و مرتب‌سازی ستونی، resize، ردیف ثابت راست ۷۸ پیکسل و عملیات فشرده ثابت در چپ.
- `../orenza/src/styles/admin.css`: فونت دانا ۱۱، زمینه گرم `#fffdf8`، سرستون `#f3ede3`، حاشیه `#e4dacb`، آیکون کوچک و صفحه‌بندی ۱۰/۲۵/۵۰/۱۰۰. همین مشخصات در `src/grid.css` پیاده شده‌اند؛ ارتفاع لیست اصلی مانند محصولات بین ۵۲۰ و ۶۴۰ پیکسل است. جدول‌های داخل پرونده و داشبورد ارتفاع محدودتر دارند.

نسخه پایدار npm در زمان نصب **ag-grid-community 36.2.0** بود و دقیقاً در package.json و lockfile تثبیت شد. هیچ قابلیت Enterprise یا مجوز تجاری نصب نشده است. کامپوننت Angular مشترک `src/app/shared/data-grid.ts`، lifecycle ساخت/حذف، ترجمه، ستون شماره، ابزارهای سلول و عملیات و ذخیره تنظیمات عرض/ترتیب ستون‌ها را مدیریت می‌کند. AG Grid از مسیر featureها lazy بارگذاری می‌شود. وابستگی JS تقریباً ۱٫۱۴ مگابایت خام / ۲۵۸ کیلوبایت انتقال است؛ CSS Material و پایه در bundle استایل‌اند.

## لیست‌های متصل

هنرجویان؛ جلسات و حضور و غیاب هر ترم؛ صورتحساب و دریافت‌های پرونده؛ کاربران در حساب/دسترسی‌ها؛ جلسات امروز، حضور معوق و ترم‌های نیازمند تمدید داشبورد. جدول HTML یا ردیف دستی جایگزین این لیست‌ها نمانده است. خلاصه اعداد، مبالغ تفکیک ارز و کارت‌های عملیاتی هر ترم، مطابق بریف باقی مانده‌اند.

هنرجویان از Infinite Row Model نسخه Community برای دریافت بلوکی از سرور و صفحه‌بندی AG Grid استفاده می‌کنند. فیلتر، مرتب‌سازی و تعداد کل در SQLite **پیش از LIMIT/OFFSET** محاسبه می‌شوند. نام فارسی، کد، تماس و وضعیت ستون‌های مجازند. مدل فیلتر و sort در سرور اعتبارسنجی و SQL پارامتری استفاده می‌شود. نرمال‌سازی ی/ي و ک/ك و شرط‌های متنی ترکیبی پشتیبانی می‌شود؛ درصد و زیرخط داخل فیلتر ستونی literal هستند. API قبلی با `page` و اندازه ۲۰ نیز حفظ شده است.

فیلتر، sort، اندازه صفحه و شماره صفحه هنرجویان در URL حفظ می‌شوند؛ صفحه پس از دریافت تعداد کل بازیابی می‌شود. داده‌های سایر gridها همان مجموعه کامل و مجازِ پاسخ موجود پرونده/داشبورد/کاربران‌اند؛ فیلتر و مرتب‌سازی کل همان مجموعه در مرورگر انجام می‌شود، بدون محدودسازی به صفحه دریافتی. مجوز سروری تغییر نکرده و در مرورگر داده مالی غیرمجاز اضافه نمی‌شود.

فقط تنظیمات ستون‌ها در sessionStorage ذخیره می‌شوند؛ داده ردیف، مبلغ و پرونده ذخیره نمی‌شود. loading/empty/error و retry واقعی‌اند. در موبایل خود AG Grid باقی می‌ماند، ستون‌ها افقی پیمایش و عملیات ثابت هستند؛ صفحه‌بندی برای جلوگیری از شکستن متن در دو ردیف تنظیم شده است. هر لیست جدید باید از همین کامپوننت مصرف کند؛ جدول HTML یا کارت جایگزین grid ساخته نشود.

فرم‌های موجود و قواعد پرداخت/جلسه/تمدید حفظ شده‌اند. فرم ویرایش جدید بدون جزئیات جداگانه کاربر ساخته نشده است. منوهای «در انتظار پیاده‌سازی» همان وضعیت را دارند؛ هنگام ساخت هر بخش، لیست واقعی و API آن به همین الگو متصل می‌شوند.

مرجع فنی مدل داده: [مستند رسمی AG Grid Infinite Row Model](https://www.ag-grid.com/javascript-data-grid/infinite-scrolling/).
