# مبنای طراحی رابط

تصمیم جاری کاربر در ۲۰ اکتبر ۲۰۲۶: **پیاده‌سازی مستقل با ظاهر و چیدمان نزدیک به Metronic 8 Demo 1**؛ نبود بسته اصلی مانع بازطراحی نیست. درخواست‌های قبلی برای دریافت بسته اصلی و ایران‌یکان دیگر پیش‌نیاز این کار نیستند.

مرجع: https://preview.keenthemes.com/metronic8/demo1/

دمو در Chrome باز و تصویر آن برای بررسی بصری مشاهده شد. عرض حدود ۲۶۵ پیکسل سایدبار، ارتفاع حدود ۷۸ پیکسل هدر، سلسله‌مراتب عنوان و breadcrumb، فاصله حدود ۲۴ پیکسل کارت‌ها، حاشیه ظریف، جدول و تراکم کنترل‌ها مبنای طراحی مستقل قرار گرفتند. RTL و محتوای عملیاتی آموزشگاه جای محتوای نمونه دمو را گرفته‌اند. کارت‌های تبلیغاتی، تصاویر، نمودارها و تزئینات دمو برای این محصول بازتولید نشده‌اند.

- پوسته، SVG آیکون‌های خطی و CSS در کد پروژه نوشته شده‌اند. هیچ فایل اختصاصی HTML/CSS/JS/فونت/تصویر قالب از preview استخراج، کپی یا hotlink نشده است.
- Bootstrap RTL موجود حفظ شده؛ بسته اصلی یا پلاگین‌های Metronic نصب نشده‌اند و این خروجی به‌عنوان ادغام اصلی قالب یا تطبیق پیکسلی کامل معرفی نمی‌شود.
- فونت فعلی دانا است: پنج وزن محلی، preload و کش shell. منبع در [FONTS.md](FONTS.md) ثبت شده است.
- سایدبار دسکتاپ جمع می‌شود؛ موبایل drawer با backdrop، Escape، مدیریت فوکوس و چرخه Tab دارد.
- تصمیم جدید کاربر: عنوان ثابت و قابل کلیک بالای تمام فیلدها، بدون حرکت هنگام فوکوس/مقدار. ورودی‌ها و Select2 به اندازه sm با ارتفاع ۳۸ پیکسل درآمدند؛ textarea کوچک با ارتفاع پایه ۸۸ پیکسل است. کنترل‌های دوحالته از سوییچ خاکستری/آبی با دستگیره سفید مشابه تصویر کاربر استفاده می‌کنند. آیکون‌ها و CSS مستقل‌اند و فایل اختصاصی دمو استخراج نشده است.
- فهرست هنرجویان روی موبایل ردیف‌های عمودی با تمام اطلاعات و عملیات دارد. جدول‌های تفصیلی پرونده و تمدید، در صورت نیاز در container افقی قابل پیمایش‌اند؛ کل صفحه سرریز نمی‌کند.

تصاویر خروجی واقعی با داده ساختگی و API/SQLite واقعی در [evidence](evidence/) هستند. بررسی موبایل در شبیه‌سازی Pixel 7 روی Chrome انجام شده و معادل بررسی دستگاه فیزیکی نیست.


## تصمیم بعدی کاربر: ظاهر لیست‌های اورنزا

در ادامه، کاربر ظاهر خود لیست‌ها را دقیقاً مطابق محصولات اورنزا و با AG Grid خواست. این تصمیم جای چیدمان قبلی جدول و کارت‌های موبایل را برای لیست‌ها می‌گیرد؛ shell همچنان طراحی مستقل الهام‌گرفته از Demo 1 است. جزئیات اجراشده در [LIST_UI_STANDARD.md](LIST_UI_STANDARD.md) ثبت شده‌اند.

آخرین اصلاح کاربر: ساختار AG Grid باقی است، ولی رنگ اورنزا کنار گذاشته شده و تم سفید/طوسی خنثی جای آن است. همه فیلترها فقط داخل خود grid (ردیف زیر سرستون و popup ستون) هستند.

درخواست بعدی برای ثبت/ویرایش هنرجو: ساختار فرم‌های ویرایش اورنزا از `../orenza/src/components/admin/AdminResourceForm.astro` و `../orenza/src/styles/admin.css` بررسی شد. فرم مستقل چندبخشی، ستون جانبی عکس/وضعیت، بخش‌های بازشونده و نوار ذخیره پیاده شدند. رنگ سفید/طوسی پنل و پوسته جاری حفظ شده‌اند؛ ادعای تطبیق پیکسلی با اورنزا نداریم. عکس‌های تصاویر آزمون فقط سطوح رنگی تولیدشده در fixture هستند؛ عکس واقعی کاربر وارد نشده است.
